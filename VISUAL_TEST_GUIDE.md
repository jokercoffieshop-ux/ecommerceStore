# 👁️ دليل الاختبار المرئي - نموذج الفئات

## 🎯 ما يجب أن تراه في كل خطوة:

---

## 1️⃣ صفحة الفئات الفارغة

عند فتح `/admin/categories` لأول مرة:

```
┌─────────────────────────────────────────────────────┐
│  📂 إدارة الفئات                    ➕ إضافة فئة جديدة │
├─────────────────────────────────────────────────────┤
│                                                     │
│              📭 لا توجد فئات حالياً                 │
│                                                     │
│           [➕ إضافة فئة جديدة]                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**ما يجب أن تراه:**
- ✅ عنوان "📂 إدارة الفئات"
- ✅ زر "➕ إضافة فئة جديدة" في الأعلى
- ✅ رسالة "لا توجد فئات حالياً"
- ✅ زر آخر "إضافة فئة جديدة" في المنتصف

## 3️⃣ بعد إضافة فئة واحدة

بعد حفظ الفئة الأولى:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  📂 إدارة الفئات                              ➕ إضافة فئة جديدة            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ✅ تم إضافة الفئة بنجاح                                                    │
│                                                                             │
├────────┬──────────────┬──────────────┬────────┬────────┬────────┬──────────┤
│ الصورة │ الاسم عربي   │ الاسم إنجليزي│ المنتجات│ الحالة │ الترتيب│ الإجراءات│
├────────┼──────────────┼──────────────┼────────┼────────┼────────┼──────────┤
│  [🖼️]  │ قهوة عربية   │ Arabic Coffee│   0    │ [نشط]  │   1    │[تعديل][حذف]│
└────────┴──────────────┴──────────────┴────────┴────────┴────────┴──────────┘
```

**ما يجب أن تراه:**
- ✅ رسالة نجاح خضراء في الأعلى
- ✅ جدول بـ 7 أعمدة
- ✅ صورة الفئة (أو أيقونة افتراضية)
- ✅ الاسم بالعربية والإنجليزية
- ✅ عدد المنتجات = 0
- ✅ badge أخضر "نشط"
- ✅ رقم الترتيب
- ✅ زرين: "تعديل" و "حذف"

## 6️⃣ فئة غير نشطة

بعد تعطيل فئة:

```
├────────┬──────────────┬──────────────┬────────┬────────┬────────┬──────────┤
│  [🖼️]  │ لاتيه        │ Latte        │   0    │[غير نشط]│   5    │[تعديل][حذف]│
└────────┴──────────────┴──────────────┴────────┴────────┴────────┴──────────┘
```

**ما يجب أن تراه:**
- ✅ badge أحمر "غير نشط"
- ✅ الفئة تظهر للـ ADMIN
- ✅ الفئة لا تظهر للعملاء

**ما يجب أن تراه:**
- ✅ عدد المنتجات = 3 (أو أي رقم > 0)
- ✅ عند محاولة الحذف: رسالة خطأ
